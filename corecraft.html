Frequently Asked Questions

Server Information

What type of server is CoreCraftMC?
CoreCraftMC is a pure survival vanilla SMP with a hardcore spirit. We offer no pay-to-play features, no Towny, no claims, and no kits - just Minecraft survival as it was meant to be.
What Minecraft version do I need?
Java Edition: Version 1.21.4 or higher
Bedrock Edition: Any recent version
How do I join the server?
Java: playcorecraftmc.com
Bedrock: bedrock.playcorecraftmc.com (Port: 19132)

Mods and Features

What mods are allowed?
We allow optimization mods (Optifine, Sodium, Lithium), ReplayMod, FreeCam, tool indicators, autoclickers for farms, surface-only minimaps, Litematica (without EasyPlace), MiniHud, and VanillaTweaks.
What mods are prohibited?
Hacked clients, X-ray, fullbright, auto-reconnect, entity/cave maps, autoslot, glowing ores, and Litematica EasyPlace mode are all prohibited.

Community Features

How do nations work?
Nations require at least 5 members including the founder. Request a nation using the support channel in Discord. Each nation receives a private channel and can recruit new members.
How do I get help or report issues?
Use the support channel in our Discord server. Create a ticket and provide details. Be kind - all moderators are volunteers.
What happens if I break the rules?
Responses to rule breaking vary by the offense. Please see the Discord for more details on rules and punishments.
